# AEVORA Story Studio manual acceptance checklist

- [ ] Desktop editor preview remains precisely 9:16 at any browser width and with sidebars open.
- [ ] Mobile preview and published viewer remain 9:16; no cropping of UI controls.
- [ ] Upload JPG, PNG, GIF and MP4. Confirm they are only published after selecting Publish.
- [ ] Add 10 images, reorder, split, duplicate, delete, undo and redo. Total must never exceed 60 seconds.
- [ ] Seek, preview, and confirm media trim and speed playback positions correspond to the timeline.
- [ ] Overlay text, emoji, images, and drawings; verify their relative positions on published video.
- [ ] Add original/licensed background music, set start, fade and volume, render and hear audio.
- [ ] Check cut and fade, cinematic, monochrome, blur and glow in exported MP4.
- [ ] Save a draft, close the editor, re-open, restore File blobs and continue.
- [ ] Try publishing at 60.0s and 60.5s; the latter must be blocked on client and server.
- [ ] Publish a multi-clip MP4; verify one story record and one optimized final MP4 in ImageKit.
- [ ] Check status progress, persistence across refresh, and retry when a job fails.
- [ ] Publish an Interactive Slides story containing a poll; voting still works and is not treated as a baked MP4.
- [ ] Unauthorized users cannot view or modify render jobs or download private source media.
- [ ] Test render on Render Free with memory monitoring; plan resource upgrades before high volume.
